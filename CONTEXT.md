# muccy.it — Personal Portfolio

The personal portfolio site for Marco Muccinelli. This glossary fixes the canonical positioning language so edits (often by agents) don't drift back to stale or inaccurate terms.

## Language

**Tech Lead**:
Marco's current role and the title the site leads with. Hands-on technical leadership: technical direction, architecture, code review, staying close to the code.
_Avoid_: Engineering Manager, Engineering Leader, Manager, Team Lead

**Imagonist (Zucchetti Group)**:
The current client/team. One continuous engagement since 2021; ownership moved from Timeware to the Zucchetti Group, the team and product stayed the same.
_Avoid_: Timeware (as the current client), Zucchetti (as employer — it is the owner, not an internal role)

**Bun Burger**:
A real QSR client brand. Always this name.
_Avoid_: Burger King

**QSR brands**:
The 20+ Quick Service Restaurant brands the team ships for (KFC, Bun Burger, Alice Pizza).
_Avoid_: enterprise projects, concurrent projects

**Flutter (Dart)**:
The current mobile stack and Marco's deepest area today.

**iOS (Swift, Objective-C)**:
Foundational/historical background (TuttoMercatoWeb era). Kept as identity and search keyword, not as the current stack.
_Avoid_: presenting iOS as the current mobile stack
